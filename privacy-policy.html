Política de Privacidad - NIAVA Publisher

Última actualización: 11 de agosto de 2026

1. Responsable del tratamiento

Nombre: Carlos de Jesus Martinez Pineda

Contacto: carlosmartinezpineda.dev@gmail.com

Rol: Desarrollador y administrador de la aplicación "NIAVA Publisher"

2. Qué datos recopilamos

La aplicación NIAVA Publisher (app ID de Meta for Developers) recopila únicamente los datos mínimos necesarios para su función: publicación automática de contenido en la página de Facebook "NIAVA" (ID: 61593080555217) bajo autorización expresa del administrador.

  • Token de acceso de página (Page Access Token): Otorgado voluntariamente por el administrador de la página a través del flujo OAuth de Meta. Este token permite publicar posts e imágenes en la página NIAVA.
  • Contenido a publicar: Texto e imágenes que el administrador proporciona a la aplicación para su publicación.
  • Datos de la página (solo lectura): Nombre, ID y foto de perfil de la página NIAVA, obtenidos vía Graph API para verificación de publicación.

NO recopilamos: datos personales de visitantes de la página, mensajes privados, emails, ubicación, contactos, ni ningún dato de terceros.

3. Finalidad del tratamiento

  • Publicar posts de texto e imágenes en la página de Facebook "NIAVA" mediante la Graph API oficial.
  • Verificar que la publicación se realizó correctamente (lectura del post publicado).
  • Gestionar el token de acceso de forma segura (almacenamiento local encriptado en la máquina del administrador).

4. Base legal

El tratamiento se basa en el consentimiento explícito del administrador de la página (Art. 6.1.a RGPD), quien autoriza la aplicación mediante el flujo OAuth de Meta y proporciona voluntariamente el token de acceso de la página.

5. Destinatarios de los datos

Los datos no se comunican a terceros. Únicamente se transmiten a los servidores de Meta (Facebook/Graph API) para ejecutar las operaciones de publicación solicitadas por el administrador.

6. Conservación de los datos

  • Token de página: Se almacena localmente mientras la aplicación esté activa. Los tokens de página de Meta no expiran salvo revocación manual.
  • Contenido publicado: No se almacena en la aplicación tras la confirmación de publicación exitosa.
  • El administrador puede revocar el acceso en cualquier momento desde Meta (Configuración de la página → Avanzada → Tokens de acceso).

7. Derechos del usuario (Administrador)

Como administrador y titular de los datos, tienes derecho a:

  • Acceso: Solicitar qué datos trata la aplicación.
  • Rectificación: Corregir datos inexactos.
  • Supresión: Eliminar el token y revocar el acceso (ver sección 8).
  • Oposición/Portabilidad: No aplicable al alcance de esta app.

8. Eliminación de datos (Instrucciones para Meta)

¿Cómo eliminar tus datos de NIAVA Publisher?

Puedes revocar el acceso y eliminar el token de acceso de la página de cualquiera de estas formas:

  1. Desde Meta (recomendado): Entra a Configuración de la página NIAVA → Avanzada → Tokens de acceso → Revoca el token de "NIAVA Publisher".
  2. Desde la app de Meta Developers: Panel de la app → Roles → Test Users o elimina la app completa.
  3. Contacto directo: Envía un email a carlosmartinezpineda.dev@gmail.com con asunto "Eliminación de datos NIAVA Publisher" y procederemos a borrar el token local en 24h.

Tras la revocación, la aplicación dejará de poder publicar automáticamente.

9. Seguridad

  • El token se almacena solo en la máquina local del administrador (archivo fb_config.json), no en servidores externos ni nube.
  • Comunicación exclusiva mediante HTTPS/TLS 1.2+ contra graph.facebook.com.
  • La aplicación no tiene backend, base de datos, ni servicios de terceros.

10. Cambios en esta política

Cualquier modificación se notificará al administrador y se actualizará la fecha de "Última actualización" al inicio de este documento.
